01 — Pregunta de Investigación

¿Cómo puede un sistema audiovisual utilizar el rostro como interfaz en tiempo real para investigar nuevas formas de interacción entre el cuerpo y los entornos digitales?

Oportunidad identificada: en el estado del arte de experiencias inmersivas en Bogotá,
el cuerpo opera de manera pasiva — mediado por dispositivos táctiles o móviles.
No existe integración del rostro como input para la creación o modulación de entornos digitales en tiempo real.
02 — Marco Teórico

Interacción encarnada & somaestética

El proyecto se sitúa en la intersección entre la filosofía fenomenológica del cuerpo y el diseño de interacción, articulando Heidegger y Merleau-Ponty a través de dos referentes centrales.

05 — Stack Técnico
// Software principal
TouchDesigner
Motor en tiempo real para la síntesis audiovisual. Recibe datos OSC y mapea parámetros faciales a outputs visuales y sonoros.
// Captura facial
ZigSim Pro
Detección de gestos faciales vía cámara frontal del dispositivo. Transmisión de datos en tiempo real por protocolo OSC.
// Protocolo
OSC
Open Sound Control — protocolo de comunicación entre ZigSim Pro y TouchDesigner. Permite el flujo de datos en tiempo real por red local.
// Parámetros OSC definidos para modulación audiovisual
faceEyeBlink
Detección del parpadeo de los ojos.
Valor: 0.0 (abierto) → 1.0 (cerrado)
faceJawOpen
Apertura de la mandíbula / boca.
Valor: 0.0 (cerrado) → 1.0 (abierto)
facePosition
Posición XYZ del rostro en el espacio.
Valor: coordenadas normalizadas

Dimensión Factor de diseño Subproblema Requerimiento Parámetros Criterio de validación
INTERACCIÓN Latencia sistema rostro → respuesta Alta latencia rompe sensación de control corporal El sistema debe responder en tiempo real (<100ms perceptible) facePosition, faceEyeBlink, faceJawOpen vía OSC Usuario percibe respuesta inmediata sin desconexión cuerpo–entorno
EXPRESIÓN Legibilidad gestual Gestos faciales ambiguos o no distinguibles por el sistema Los 3 parámetros deben mapearse a outputs diferenciados y significativos Parpadeo → trigger / mandíbula → intensidad / posición → navegación Usuarios identifican relación gesto → efecto en ≤ 2 min de exploración
CORPORAL Comodidad y agencia del cuerpo Posición estática o incómoda desmotiva la interacción El sistema debe permitir movimiento natural sin restricción de postura facePosition: rango espacial amplio; sin calibración rígida Usuarios reportan sensación de libertad / agencia en entrevista post-prueba
AUDIOVISUAL Coherencia modal sonido–imagen Desconexión perceptiva entre output visual y sonoro Parámetros faciales deben modular simultáneamente visual y audio de forma coherente Mismo valor OSC → capa visual + síntesis sonora en paralelo Usuarios describen experiencia como unitaria (no fragmentada) post-sesión
INMERSIÓN Ausencia de mediación visible Dispositivos o interfaces visibles rompen la ilusión inmersiva El rostro debe operar como única interfaz sin artefactos físicos adicionales Sensor: cámara frontal discreta; sin wearables; sin tocar nada Usuarios no mencionan el dispositivo como elemento disruptivo
07 — Territorio abierto

¿Qué creará exactamente el rostro?
La pregunta que aún espera respuesta.

Esta incertidumbre es parte del proceso Research Through Design —
el prototipado iterativo revelará qué forma toma el entorno.
Posibilidad A

Visuales reactivas puras — geometrías, campos de partículas o shaders que responden en tiempo real a los tres parámetros OSC, sin componente sonoro.

Posibilidad B

Sistema audiovisual integrado — el rostro modula simultáneamente síntesis visual y sonora: parpadeo como trigger, mandíbula como intensidad, posición como timbre.

Posibilidad C

Entorno narrativo o generativo — el rostro no solo modula sino que construye: cada gesto deposita capas en un entorno que se acumula y transforma en el tiempo.
